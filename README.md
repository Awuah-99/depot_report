# DEPOT REPORT
## ABOUT
This is a simple tool that helps Bulk Oil Distribution Companies and
Oil Marketing Companies field representatives and other stakeholders who
do not have access to depot specific report to track depot loading activities.

This tool is limited to **order status report only**.  

### INSTALLATION
For command-line:
Make use your have python3 and git on your machine.
$ git clone https://github.com/Awuah-99/depot_report/
$ cd depot_report 
$ pip3 install -r requirements.txt
$ python3 main.py --help 

The --help command provides usage details

## SETTING UP
create a .env file
$ touch .env 
$ cat envexample > .env
open .env and fill in your environment secrets
eg. if you're stationed at Sentuo Oil Refinery,
Use DEPOT=Sentuo.
